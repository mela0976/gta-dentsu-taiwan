SLIDE 7 / 8 · DEPLOYMENT & HONEST SECURITY AUDIT 部署思路與資安自評 15%

部署思路與誠實資安自評：純靜態、零個資、分層防護

🚀 部署思路：GitHub Pages + 單檔離線版

  • 符合純前端需求：無需帳密與伺服器，ES Modules 靜態架構搭配 SHA-256 防快取版本，公開連結一秒開玩。
  • CI 與本機雙重驗證：GitHub Actions 每次推送跑 npm test（13/13）＋ npm run check（463 檔）；17 視窗 E2E 於部署前本機實測。

🔒 誠實資安自評（無後端／零蒐集）

  • 零資料庫／零個資：不蒐集玩家資料或客戶機密，進度僅存於瀏覽器本機 localStorage。
  • 金鑰分級隔離：VoAI / Gemini 等私密合成金鑰僅留本機且不進 Git；前端僅注入 Google Maps 瀏覽器公開 Client Key（受 HTTP Referrer 白名單與配額限制）。
  • 外洩檢查：npm run check 掃描無 .pdf/.indd/.env 與第三方 CDN（0 leaks）。
